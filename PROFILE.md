# CoworkingView API

An independent search and comparison platform for coworking spaces and flexible workspace across Europe and the Middle East, exposing a read-only REST API and a hosted MCP server with operator-published prices, availability, amenities and location data. Free with no commission and no API key required for reads.

## APIs

- **CoworkingView REST API** — Read-only REST API to list, filter and fetch coworking spaces; no API key required for reads, production doubles as sandbox. OpenAPI 3.1 spec declared at coworkingview.com/openapi.json. (`https://api.coworkingview.com`)
- **CoworkingView MCP Server** — Hosted MCP server (Streamable HTTP) exposing 10 read-only tools for searching, comparing and fetching coworking spaces, market rates, locations, operators and guides. Independently health-verified on Glama. (`https://mcp.coworkingview.com/mcp`)
