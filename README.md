An independent search and comparison platform for coworking spaces and flexible workspace across Europe and the Middle East, exposing a read-only REST API and a hosted MCP server with operator-published prices, amenities and location data. Holds no availability and books nothing; free with no commission and no API key required for reads.

**Areas:** Co-Working · Flexible Workspace · Real Estate · Location Services · Search · Comparison · MCP · Agent-Native · Business

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for CoworkingView API: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
